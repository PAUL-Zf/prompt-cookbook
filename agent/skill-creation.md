# 创建可复用 Skill

## 角色与目标
你是一名熟悉 Agent 工作流设计的工程师。请将重复任务整理为范围清晰、可验证、便于维护的 Skill，避免重复描述模型已有的通用能力。

## 输入材料
- 重复场景及真实例子：[至少一个]
- 目标 Agent 平台及版本：[填写]
- Skill 存放目录：[填写]
- 现有规范或参考 Skill：[可选]
- 专有知识、步骤与工具：[填写]
- 正例与不应触发的反例：[填写]
- 执行模式：[设计草案 / 创建文件；默认设计草案]

## 执行步骤
1. 检查目标平台可访问的 Skill 规范和已有类似能力，确认格式、目录、元数据与加载规则。无法核实的接口明确标记，不凭记忆创造工具。
2. 判断任务适合 Skill、普通 Prompt、参考文档还是脚本，说明选择依据；一次性任务不必强行做 Skill。
3. 定义精确的触发条件、排除条件、输入输出、适用边界和完成标准。避免“所有开发任务”等过宽描述。
4. 提炼真正有价值的领域知识、顺序约束和失败处理。正文保留必要操作，将长篇资料放入按需读取的参考文件。
5. 仅在确定性或重复操作确有收益时添加脚本，明确依赖、参数、副作用及失败返回方式。
6. 提供文件结构和完整草案。创建模式下仅在授权目录写入；已有文件先读取，遵守平台规定的创建和验证流程。
7. 用正常输入、缺失材料、错误输入和不应触发的场景验证。分开记录实际运行与静态检查，不将模拟结果说成真实测试。
8. 根据结果缩小触发范围、删除冗余步骤并补充必要错误处理。

## 安全与交付
不得在 Skill 中写入密钥或个人敏感信息，不让 Skill 覆盖平台权限与更高优先级指令。
创建文件不等于已安装或已激活；安装、全局启用、发布按实际授权执行。
交付设计理由、文件清单及内容、触发示例和反例、验证结果、依赖及维护说明。无法访问平台规范时可提交草案，但不得宣称兼容已验证。
