# 上下文配置审计

我已经积累了大量为早期 AI 模型编写的自定义指令（Custom Instructions）、技能（Skills）、AGENTS.md、CLAUDE.md、记忆（Memory）以及其他上下文配置。请对这些内容进行一次系统性审计，检查你会自动加载哪些内容，以及在执行任务时实际会引用哪些内容。识别哪些内容提供了真正有价值的知识，哪些与你现有的原生能力重复，哪些增加了不必要的工作量，或导致回答变得冗长、难以阅读。同时，检查是否存在相互冲突的指令、已经过时的工具、触发范围过于宽泛的 Skills，以及陈旧的事实或未经验证的假设。
